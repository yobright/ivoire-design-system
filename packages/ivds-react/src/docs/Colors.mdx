# Couleurs

Le systeme de couleurs IVDS est organise en trois couches : **brand**, **semantic** et **UI**.

---

## Brand — Identite visuelle

Les couleurs brand incarnent l'identite ivoirienne. L'**orange signature** primaire
evoque la terre et la chaleur du pays, tandis que le **teal institutionnel** represente
la croissance et le developpement.

### Primary — Orange signature

| Token | Valeur | Usage |
|-------|--------|-------|
| `--color-brand-primary-50` | `#fff4e6` | Backgrounds subtils |
| `--color-brand-primary-100` | `#ffe8cc` | Hover backgrounds |
| `--color-brand-primary-200` | `#ffd8a8` | Bordures legeres |
| `--color-brand-primary-300` | `#ffc078` | Icones secondaires |
| `--color-brand-primary-400` | `#ffb457` | Actions secondaires |
| `--color-brand-primary-500` | `#ff9f1c` | **Couleur principale** |
| `--color-brand-primary-600` | `#f08c00` | Hover |
| `--color-brand-primary-700` | `#e67700` | Active/pressed |
| `--color-brand-primary-800` | `#d9480f` | Texte haute contraste |
| `--color-brand-primary-900` | `#b45309` | Emphase profonde |
| `--color-brand-primary-950` | `#7c2d12` | Quasi-noir chaud |

## Semantic — Feedback utilisateur

Les couleurs semantiques communiquent l'etat du systeme a l'utilisateur.

| Categorie | Token 500 | Usage |
|-----------|-----------|-------|
| Success | `#19895d` | Validation, confirmation |
| Warning | `#ce790b` | Avertissement, attention |
| Error | `#d73a50` | Erreur, danger |
| Info | `#1f6fe5` | Information, aide |

---

## Usage en CSS

```css
.my-component {
  background-color: var(--color-brand-primary-50);
  color: var(--color-brand-primary-900);
  border: 1px solid var(--color-brand-primary-200);
}

.my-component:hover {
  background-color: var(--color-brand-primary-100);
}
```

## Usage en React

```tsx
import { ThemeProvider } from '@ivds/react';

// Les tokens sont disponibles via CSS custom properties
<ThemeProvider mode="light">
  <Button variant="primary">Action</Button>
</ThemeProvider>
```
